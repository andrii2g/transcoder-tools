vtx test utility

HLS playlist player

Use this page to test a generated .m3u8 master playlist or variant playlist from a local vtx HLS output folder.

Serve the repository root over HTTP, then open this page and load /out/hls/master.m3u8.

Start serverFrom the repository root, run python3 -m http.server 8080 or any static web server.
Open pageVisit http://localhost:8080/docs/hls-player.html?src=/out/hls/master.m3u8.
Browser supportSafari uses native HLS. Other browsers use hls.js from a CDN.
